# Архитектура `sql-gateway`

## Что это

FastAPI-сервис для **безопасного** доступа к PostgreSQL.

**Зачем:** AI-агенты (RAG, CRM) не должны ходить в БД напрямую. Они идут в API.

## Общая схема
AI-агент / CRM / n8n
↓
[FastAPI] ← API-ключ
↓
[PostgreSQL]

## Модули

### `app/core/config.py`

**Что делает:** загружает настройки из `.env`.
**Зачем:** не хардкодить пароли.
**Связи:** используется всеми модулями.

### `app/db/session.py`

**Что делает:** создаёт `engine` и `async_session_maker`.
**Зачем:** подключение к БД.
**Связи:** используется в `api/`.

### `app/db/base.py`

**Что делает:** `Base` — базовый класс моделей.
**Зачем:** все модели наследуются.
**Связи:** используется в `models/`.

### `app/models/transaction.py`

**Что делает:** модель `Transaction` (таблица `transactions`).
**Зачем:** структура данных в БД.
**Связи:** Alembic → миграция.

### `app/schemas/transaction.py`

**Что делает:** Pydantic-схемы (`Create`, `Read`, `Update`).
**Зачем:** валидация данных в API.
**Связи:** используется в `api/`.

### `app/api/transactions.py`

**Что делает:** CRUD-эндпоинты для `transactions`.
**Зачем:** API для клиентов.
**Связи:** `models/` + `schemas/` + `db/`.

### `app/main.py`

**Что делает:** FastAPI-приложение.
**Зачем:** точка входа.
**Связи:** `api/`.
